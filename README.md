# CIP-B1O2_Data-Carving-with-XXD-Binwalk-and-Scalpel
A digital forensics laboratory implementation and comprehensive analytical report covering file carving, signature-based recovery, metadata extraction, and data-unit examination on raw disk images (FAT12, FAT16) and media samples using Kali Linux, xxd, The Sleuth Kit (TSK), binwalk, dd, and Scalpel.
